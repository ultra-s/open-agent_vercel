========================================
FreeModel OpenAI-Compatible Setup
========================================

Add these environment variables to use FreeModel as your AI provider:

GATEWAY_BASE_URL=https://api.freemodel.dev
GATEWAY_API_KEY=fe_oa_42584285cb4c7b402135c231a50adc183b578d1eb29fd41f
GATEWAY_FORMAT=openai-compatible
GATEWAY_PROVIDER_NAME=FreeModel

========================================
How to Set Them Up
========================================

LOCAL DEVELOPMENT:
1. Create apps/web/.env.development.local
2. Paste the variables above
3. Run: pnpm db:migrate:apply
4. Run: pnpm dev
5. Send a chat message to test

PRODUCTION (Vercel):
1. Go to your Vercel project dashboard
2. Settings → Environment Variables
3. Add each variable above
4. Redeploy the project
5. Test in production

========================================
How It Works
========================================

Priority order:
1. BYOK models you configured in Settings → BYOK
2. Active BYOK connection (Settings → BYOK → Mark as Active)
3. FreeModel (if env vars are set)
4. Default Vercel AI Gateway

Example routing:
- "anthropic/claude-opus-4.6" → Sends as "claude-opus-4.6" to FreeModel
- "openai/gpt-4-turbo" → Sends as "gpt-4-turbo" to FreeModel
- "google/gemini-2-flash" → Sends as "gemini-2-flash" to FreeModel

GATEWAY_API_KEY=your-api-key
GATEWAY_FORMAT=anthropic
GATEWAY_PROVIDER_NAME=My Proxy

========================================
Troubleshooting
========================================

If messages get stuck on "thinking":
- Check the browser console for error messages
- Verify GATEWAY_API_KEY is correct
- Verify GATEWAY_BASE_URL is publicly accessible
- Check that model names are supported by the endpoint

If you see "BYOK authentication failed":
- Double-check your API key
- Make sure it hasn't been rate-limited or revoked
- Test the endpoint manually with curl

For more details, see FREEMODEL_SETUP.md
